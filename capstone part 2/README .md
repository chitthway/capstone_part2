# 🚗 Metro Interstate Traffic Analytics Pipeline & CLI

An end-to-end, reproducible Python data pipeline and analytics tool developed for the NUS Data Science and AI Capstone Project.

## 📂 Project Structure
- pipeline.py
- feature_engineering.py
- visualizations.py
- app.py
- pipeline.log
- plots/ (Contains 3 charts)
- README.md

## 🚀 How to Run
1. Run pipeline: `python pipeline.py`
2. Run feature engineering: `python feature_engineering.py`
3. Generate plots: `python visualizations.py`
4. Run CLI app: `python app.py`
